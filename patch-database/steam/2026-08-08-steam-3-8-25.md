## Contents of update

### Changelog
- This update is for the SteamOS Beta and Preview channels, and includes new features that are still being tested. You can opt into this in Settings > System > System Update Channel.
- General: Added support for waking up from the Steam Controller Wireless Adapter (2015)
- Steam Machine Firmware 108: Fixed an issue where the system could occasionally wake up immediately after going to sleep
- Audio: Fix for HDMI audio dropouts with some game and TV combinations
- Non-Valve Devices: Improve support for MSI Claw and OneXPlayer device variants
- Developer: Updated the Linux kernel to 6.18.42
- General: Improved battery indications when the device is charging in but using more power than the charger can provide
- Steam Machine Firmware 108: Fixed a rare issue where CPU performance could be degraded until reboot after waking up from sleep
- Audio: Improve reliability of HDMI hotplug detection
- Non-Valve Devices: Improve support for devices with external or no Wi-Fi adapters
- General: Preliminary support for the Steam Frame Wireless Adapter
- Audio: Add option to prefer lower latency audio codecs for Bluetooth devices

### Known issues
- There is a known issue with degraded performance in some cases when composition is required (such as when having FSR enabled). This issue is fixed in the latest SteamOS stable release (3.8.16). Affected users may wish to switch to the stable update channel while we work on bringing this fix to the beta channel.
